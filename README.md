# Clx-language


您可以使用本插件开发基于LUA扩展语法的CLX程序，该程序可在Lifesmart发布的ColoPlay设备上运行，该插件提供了开发测试相关环境，您可以使用该插件实现：

- CLX语法高亮、语法提示
- ColoX相关接口提示
- 编译文件并在ColoX模拟器中运行


## 运行环境

本插件目前仅支持Win32和OSX环境，并且需要预先配置好JAVA环境
